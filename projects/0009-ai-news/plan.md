# 計画: 今日時点の最新AI News 5点

## 目的（再定義）
2026-10-04 時点で直近に報じられた、世界規模で重要なAI関連ニュースを5件選び、各件を日本語500文字以内で要約する。各件に出典と公開日を付け、選定理由が分かること。

## 受入基準
| ID | 基準 | 重み |
| --- | --- | --- |
| a1 | ニュースがちょうど5件掲載されている | 3 |
| a2 | 各要約が日本語で500文字以内（空白含む）である | 3 |
| a3 | 各ニュースの公開日が明記され、すべて取得日2026-10-04から14日以内である | 3 |
| a4 | 各ニュースに出典URLと取得日が付いている | 2 |
| a5 | 5件が米国・欧州・アジアのうち2地域以上、かつ異なる3組織以上から構成される | 2 |
| a6 | 各要約に「何が起きたか・誰が関与か・なぜ重要か」が含まれる | 2 |
| a7 | 各ニュースの選定理由欄に、影響範囲または主要国際メディアでの言及状況が記載されている | 2 |

## 採用しなかった批評とその理由
- 「レポート全体の構成やフォーマットの規定」: 構成は research.md の report.md 構成に既に定められているため、基準としては追加しない。
- a8 の「主要国際メディア言及」を必須とする案: a7 に「影響範囲または言及状況」の選択式で取り込み、メディア名を限定する条件は採用しない（公式発表が一次情報になりうるため）。
