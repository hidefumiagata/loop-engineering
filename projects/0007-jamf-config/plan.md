# plan: Jamf Pro 推奨設定（日本の上場企業・金融系 Mac）

## 目的（再定義）
日本の上場企業（金融系業務を含む）が管理する Mac 端末を想定し、Jamf Pro で構成できる管理項目を網羅的に一覧化する。そのうえで各項目に、金融・上場企業のセキュリティ要求（内部統制、FISC安全対策基準、個人情報保護法等）に照らした推奨設定値と根拠を示す。

## 受入基準
| ID | 基準 | 重み |
| --- | --- | --- |
| a1 | Jamf Pro で設定可能な項目がカテゴリ別（セキュリティ/ネットワーク/アプリ配布/アカウント/更新管理/インベントリ等）に表で列挙され、各項目に管理方式（構成プロファイル/ポリシー/スクリプト等）が明記されている | 3 |
| a2 | 主要セキュリティ項目（FileVault、ファイアウォール、Gatekeeper、パスワードポリシー、画面ロック、USB/外部メディア制限、MDM/システム拡張承認、macOS更新制御、SSO/Platform SSO）それぞれに具体的な推奨設定値が表に記載されている | 3 |
| a3 | 各推奨値に、対応する規制・基準（FISC安全対策基準、個人情報保護法、J-SOX、CIS/NIST mSCP等）への対応表が付き、紐付けの粒度（条文番号/章/未確認）が各行に明記されている。確認できなかった番号は推測で埋めず「未確認」と書かれている | 3 |
| a4 | 各項目の仕様・設定値の出典が公式ドキュメントURLと取得日付きで示され、公式に無い情報は「非公式のみ」と区別されている | 2 |
| a5 | 業務影響が大きい設定（更新強制、USB制限等）について、例外運用・段階導入の推奨と、設定同士の競合・適用困難ケースの注意が記載されている | 2 |
| a6 | 前提とした Jamf Pro / macOS のバージョンが明記されている | 1 |
| a7 | 金融特有の追加要件（DLP連携、EDR、証跡・ログ保管、紛失時のロック/ワイプ）の推奨が記載されている | 2 |

## 採用しなかった批評とその理由
- a8（FISC の該当項目番号または J-SOX 統制目標との1対1/1対多対応表を必須とする案）: 部分採用。FISC 基準は有償配布で公式本文を Web で確認できない可能性が高く、番号を必須にすると推測で埋める誘因が生じる。そのため a3 に統合し、「粒度を明記し、確認できない番号は未確認とする」とした。
- 批評の「競合設定・適用困難ケースの注意」: 採用し a5 に統合した。
