# 計画: AI臭さを消す方法

## 目的（再定義）
AIが生成したドキュメント・スライドをそのまま人に見せる場面で、読み手が「AIが書いた」と感じて信頼や納得を損なう要因（AI臭さ）を、
インターネット上の文献から調査・分析し、原因ごとの対策を立案して、AIに与えられる指示プロンプトとして明文化する。
プロンプト作成までが範囲。実運用での効果測定は範囲外。

## 受入基準
| ID | 基準 | 重み |
| --- | --- | --- |
| a1 | 異なる出典10件以上を調査し、各件の URL・種別（公式 / 学術 / 実務者・その他）・取得日が sources.md に記載されている | 3 |
| a2 | AI臭さの原因が分類され、各原因に少なくとも1件の出典が紐づいて report.md に明記されている | 3 |
| a3 | 明記された原因すべてに対応する対策が対応表で示され、対策の無い原因が0件である | 3 |
| a8 | 「AI臭さ」が具体的な言語的・構成的特徴のリスト（例: 過度な丁寧語、冗長な接続詞、断定回避、定型的な三点列挙）として report.md で定義され、プロンプトがそれらを抑制する指示を含む | 3 |
| a4 | 対策を反映した指示プロンプトが、ドキュメント用とスライド用の双方についてコードブロックで全文掲載されている | 2 |
| a5 | プロンプト内の各指示が、どの原因・対策に対応するか辿れるトレーサビリティ表がある | 2 |
| a6 | 出典を種別で区別し、種別間の主張の相違・出典の限界が report.md に記載されている | 1 |
| a7 | 対策の限界（直せない臭さ・副作用）が明記されている | 1 |

## 採用しなかった批評とその理由
- 「プロンプトが実際に臭さを減らすかの評価基準が無い」: 効果測定は Issue の範囲外（プロンプト作成まで）のため採用しない。a7 で限界を明記させる。
- a6 の「公式/非公式」が曖昧: 採用。a1 で種別を定義し、a6 は「種別間の相違」に書き換えた。
- 「全文掲載の形式」: 採用。a4 にコードブロックと明記。
- a8（AI臭さの定義リスト）: 採用。
