## 3. Deno チームが Cloudflare に参画、Deno ランタイムは1年後に開発終了

- **発表元 / 媒体**: Deno（Ryan Dahl）
- **日付**: 2026-10-09（24時間以内）
- **一次情報**: [Deno is joining Cloudflare](https://deno.com/blog/cloudflare)
- **参考**: なし

Deno の創業者 Ryan Dahl は、Deno チーム全体が Cloudflare に参画すると発表した。今後の開発は Cloudflare Workers と Durable Objects を基盤にした共有プラットフォームに集中する。Deno ランタイムは1年間、毎月の更新を続けたのち開発を終了し、Deno Deploy は6か月後に停止する。ランタイムはオープンソースのまま残り、他者が引き継ぐことは歓迎するという。AI との関連は、Durable Objects が安価なサーバーレス実行と永続状態、WebSocket を持つためエージェントの実行基盤に向くと述べている点にある。AI 専業の発表ではないが、エージェントの実行環境を巡る基盤事業者の再編として拾った。Deno 利用者は、1年以内に移行先を決める必要がある。

## 5. OpenAI の Decisions API が Vercel AI Gateway で利用可能に

- **発表元 / 媒体**: Vercel（OpenAI の API を提供）
- **日付**: 2026-10-07（2日前）
- **一次情報**: [OpenAI Decisions API now available on AI Gateway](https://vercel.com/changelog/openai-decisions-api-now-available-on-ai-gateway)
- **参考**: [OpenAI's Jev clone could help the frontier lab stop its swarming agents](https://techcrunch.com/2026/09/30/openais-jev-clone-could-help-the-frontier-lab-stop-its-swarming-agents)（2026-09-30）

Vercel は、OpenAI の Decisions API を AI Gateway の `/v1/decisions` で使えるようにした。決定モデルは、同じ入力に対する型付きの質問に答える。ある条件が成り立つ確率を問う predicate、選択肢から選ぶ choice、順序付きの基準で採点する score の3種類があり、文章は生成しない。用途は分類、ルーティング、トリアージ、基準に沿った採点で、OpenAI の SDK なら接続先と認証情報、モデル ID を替えるだけで切り替えられる。OpenAI の GPT-6 Luna Decisions のほか、Jev などもこの形式で呼べる。9月30日に Sam Altman が発表した API が実際の開発基盤に載ったことで、決定モデルが LLM の使い分け先として定着し始めた。OpenAI 自身の提供開始日は未確認。
